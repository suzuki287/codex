# 24スイーツショップ岡山店　リール動画 AI自動化プラン

## 1. 結論

**「撮影だけは人がやる、それ以外はAIで流す」半自動の仕組みにするのが一番の近道です。**

- 人がやるのは **週1回・30分の素材撮影**（スマホで縦の短いクリップを撮るだけ）と、**投稿前の最終チェック（1本1分）** の2つだけ。
- 企画・台本・テロップ・キャプション・ハッシュタグ・編集・予約投稿はAIとツールで自動化。
- 目標：**週3〜5本のリール投稿を、担当者の作業 月4時間以内** で回す。

無人店舗は「スタッフがいない＝発信する人がいない」になりがちです。逆に言うと、発信を仕組み化できれば無人店舗の強み（24時間・非対面・気軽さ）をそのまま集客に変えられます。

---

## 2. 理由（なぜ「完全自動」ではなく「半自動」か）

| 観点 | 完全AI生成（動画生成AIだけで作る） | 半自動（実写素材＋AI編集） |
|---|---|---|
| 食品の「おいしそう感」 | 弱い。実物と違うと逆効果・景表法リスク | 実物なので信頼される |
| 来店につながるか | 低い（どこの店か伝わらない） | 店舗外観・自販機・実商品で「行ける」と分かる |
| 手間 | ほぼゼロ | 週30分の撮影のみ |
| コスト | 生成AI月額が高め | Claude API 月数百円＋既存ツール |

→ **素材は実写、頭脳労働と編集はAI** が費用対効果のベストバランスです。
AI生成映像は「季節の背景」「イメージカット」など補助的に使う程度に留めます。

---

## 3. 全体フロー（週次で回す）

```
【月曜 10分】商品リスト更新（Googleスプレッドシート）
      │ 新商品・季節限定・在庫多めの商品に印をつける
      ▼
【自動】Claude が 1週間分のリール企画を生成
      │ フック／カット割り／テロップ／キャプション／ハッシュタグ／撮影指示
      ▼
【火曜 30分】撮影指示書どおりにスマホで素材撮影（1カット3〜5秒）
      │ Googleドライブの「素材」フォルダへアップ
      ▼
【自動】動画を自動編集（縦9:16・テロップ焼き込み・BGM・尺15〜20秒）
      ▼
【1本1分】担当者が確認 → OKなら予約投稿（Meta Business Suite）
      ▼
【月末 自動】インサイトを集計 → 伸びた型を翌月の企画に反映
```

## 4. 各工程の具体策

### ① 企画・台本（Claude で自動化）★本リポジトリで実装済み
- 入力：商品CSV（商品名・価格・特徴・季節性・推したい度）
- 出力：1本ごとに以下を自動生成
  - 冒頭1.5秒のフック（例：「深夜2時、無性に甘いものが欲しくなったら」）
  - カット割り（3〜5カット）と各カットの撮影指示
  - 画面テロップ
  - キャプション（来店導線・営業時間・場所を必ず含める）
  - ハッシュタグ（#岡山スイーツ #岡山グルメ #無人販売 など地域＋ジャンル）
  - BGMの雰囲気
- スクリプト：`reel_automation/generate_reel_plan.py`

### ② 企画の「型」を固定して当たり率を上げる
無人スイーツ店で反応が取りやすい型を6つに絞り、AIに順番に回させます。

| 型 | 内容 | 狙い |
|---|---|---|
| 深夜・早朝訴求 | 「夜中でも買える」 | 24時間の強みを刷り込む |
| 開封・断面ASMR | 箱を開ける→断面アップ | 保存・シェアされやすい |
| 買い方ガイド | 自販機の使い方を15秒で | 初来店のハードルを下げる |
| 新商品・季節限定 | 「今週から入荷」 | 再来店のきっかけ |
| ランキング | 「売れ筋TOP3」 | 迷う人の背中を押す |
| 手土産提案 | 「急な手土産に」 | 客単価アップ・用途拡大 |

### ③ 撮影（人がやる部分を最小化）
- AIが出した **撮影指示書（カットごとに「何を・どの角度で・何秒」）** を見て撮るだけ。
- 撮影ルール：縦・明るい場所・1カット3〜5秒・手ブレ防止に両肘を固定。
- 1回の撮影で **2週間分（10〜15カット）** まとめ撮り。
- 外観・自販機・店内の汎用カットは一度撮れば使い回し可能（「素材ストック」フォルダ化）。

### ④ 編集（自動化）★本リポジトリで実装済み
- `reel_automation/render_reel.py`：企画JSONとクリップから、
  縦1080×1920・テロップ入り・BGM付きのmp4を自動生成（ffmpeg使用・無料）。
- より凝った見た目にしたい場合の選択肢：
  - **Canva 一括作成**：企画CSVをそのまま流し込んでテンプレに差し込み
  - **CapCut テンプレート**：店舗用テンプレを1つ作り、素材差し替えのみ
  - **Vrew**：ナレーション（AI音声）＋自動字幕を付けたい場合

### ⑤ 投稿（予約投稿）
- **Meta Business Suite** でInstagram／Facebookに同時予約投稿（無料）。
- 投稿時間の目安：平日 **20〜22時**（夜のスイーツ欲求）、土日 **11〜13時**（お出かけ前）。
- 同じ動画を **YouTubeショート・TikTok** にも転載して露出を3倍に（アジャイルパートナーズのYouTube運用ノウハウを横展開）。
- 完全自動投稿まで進める場合は Instagram Graph API／Make（旧Integromat）で連携可能。ただし最初は「人が最終確認して予約」の方が事故（価格違い・売切れ商品の宣伝）を防げます。

### ⑥ 分析・改善（月1回・自動集計）
- インサイト（再生数・保存数・シェア数・プロフィールアクセス）をスプレッドシートに記録。
- Claude に「伸びた型・伸びなかった型」を分析させ、翌月の型の配分を変える。
- KPI：**保存率**（保存÷リーチ）と **プロフィールアクセス→ルート検索** を重視。再生数だけ追わない。

## 7. 注意点（ここだけは人が守る）

1. **価格・商品情報の正確性**：AIの出力は投稿前に必ず人が確認（景品表示法対策）。商品CSVを常に最新に。
2. **売切れ商品を宣伝しない**：在庫が少ない商品は CSV の「推したい度」を0にする。
3. **お客様の映り込み**：店内撮影時は人が映らないように（無人店でも防犯カメラ・他のお客様に注意）。
4. **BGMの権利**：Instagram内の音源ライブラリか、商用利用可能なフリー音源のみ使用。
5. **食品表示**：アレルギー表示や「無添加」等の表現はAIに勝手に書かせない（プロンプトで禁止済み）。

## 8. 横展開（グループ事業への応用）

同じ仕組みは商品CSVを差し替えるだけで流用できます。
- **ミライノサチ**：ヒレナマズの調理動画・レシピリール
- **Leafia**：保護犬猫の日常リール（譲渡促進）
- **瀬戸風月**：客室紹介・高松観光リール（インバウンド向けに英語キャプションも自動生成）
- **アジャイルパートナーズ**：この仕組み自体を「中小店舗向けリール自動化パッケージ」として商品化
